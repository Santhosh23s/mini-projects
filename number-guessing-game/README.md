# Number Guessing Game (Java)

A simple CLI game where the player tries to guess a randomly generated number.

## Features

- Random number generation
- User input handling
- Feedback system (high / low)
- Attempt counter

## Concepts Used

- Java Random class
- Scanner input
- while loops
- conditional statements

## Example Output
````
Guess the number between 1 and 100
Enter guess: 50
Too low 
Enter guess: 80
Too high
Enter guess: 65
Congratulations! you guessed it in 3 guesses
Play again(Y/N): N
Bye!
````

# Bank Management System (Java)

A console-based Bank Management System built using core Java concepts.

## Features
- Create Savings and Current accounts
- Deposit and withdraw money
- Overdraft handling for Current accounts
- Minimum balance enforcement for Savings accounts
- Custom exception handling
- Menu-driven console interface

## Concepts Used
- OOP (Abstraction, Inheritance, Polymorphism)
- Abstract classes
- Exception handling
- HashMap for account storage
- Scanner for user input

## How to Run
```bash
javac src/Main.java
java src.Main
